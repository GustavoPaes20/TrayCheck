# TrayCheck
TrayCheck é um sistema de checklist de instrumentos cirúrgicos pré-cirurgia, operado por comandos de voz. Permite cadastrar instrumentais, kits e procedimentos, conferir itens por voz e registrar divergências, reduzindo erros e aumentando a segurança do paciente. Projeto acadêmico em Scrum, 5 sprints, com equipe de 7 integrantes.
